# 💗 Birthday Website

A romantic 5-page birthday surprise made with HTML, CSS and JavaScript.

## Folder structure

birthday-website/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── photo1.jpg
│   ├── photo2.jpg
│   ├── photo3.jpg
│   ├── photo4.jpg
│   ├── photo5.jpg
│   └── photo6.jpg
└── audio/
    └── birthday-song.mp3

## Personalize it

Open `script.js` and change:

```js
const girlfriendName = "BABY";
const yourName = "YOUR NAME";
```

The birthday messages are inside `index.html` and `script.js`, with comments showing where to edit them.

### Photos
Replace the six placeholder files in `/images/`:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg
- photo5.jpg
- photo6.jpg

The gallery will still show online placeholders if a local image is missing.

### Music
Put your MP3 at:

`audio/birthday-song.mp3`

The site intentionally does **not** autoplay music. Click the music button in the top-right corner.

## Run locally

Double-click `index.html` in a modern browser.

Everything is client-side. No backend is required.
